【第一步】装 Python
  你现在这台机器上没有 Python（那个 python 是微软商店的空壳）。
  1. 打开 https://www.python.org/downloads/
  2. 点黄色大按钮下 Python 3.12（Windows installer 64-bit）
  3. 装的时候，第一页最下面有个勾选框：
        [x] Add python.exe to PATH
     这个勾必须打上，不然一会儿还是找不到。
  4. 装完把安装窗口全关掉。

  验证：按 Win+R，输入 cmd 回车，敲
        python --version
  看到 Python 3.12.x 就对了。看到 "not found" 说明勾没打上，
  最省事的办法是重装一遍。

【第二步】双击「双击启动.bat」
  第一次会自己建虚拟环境、装依赖、导数据，大概 1-2 分钟。
  跑完浏览器会自动打开 http://127.0.0.1:8000

  * 那个黑色命令行窗口是服务器本体，别关。
  * 想停服务，关掉黑窗口就行。
  * 页面打不开、显示 "连不上本地服务"，就是黑窗口被关了，
    重新双击一次。

=========================================
  几个你可能想问的
=========================================

Q: 数据传到网上了吗？
A: 没有。服务只监听 127.0.0.1，就是只有这台电脑能访问。
   群聊记录和图片都在你自己硬盘上。

Q: 聊天数据全吗？
A: 现在库里是 483 条（原始 484 条，其中 1 条是纯图片没文字，跳过了）。
   AstrBot 只存了这么多（它有自己的保留策略），不是导入失败。

Q: 表情包 122 张，包括哪些？
A: 两套：dafeiyu-learned 31 张、whale-girl-emoji 91 张。
   每张图的描述是之前用模型生成过的 caption，直接拿来做检索文本。

Q: 我想加分 / 改代码怎么办？
A: 这本来就是个练手项目，随便改。
   改之前先看一眼 README 里的「目录结构」，知道每个文件管什么。

Q: 评测是啥？
A: 在 group-brain 目录下开个 cmd，跑
        .venv\Scripts\python.exe scripts\run_eval.py
   会输出 Recall@5 和 MRR。这两个数就是你后面对比"向量检索有没有用"
   的唯一依据。我提前跑过一遍：Recall@5 0.938，MRR 0.823（16 条查询）。
   先记下来，v0.4 之后要拿它对比。
