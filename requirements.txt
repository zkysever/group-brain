# 直接依赖写在这，间接依赖让 pip 自己解。
#
# 为什么用 `~=` 而不是 `==` 钉死到小版本：
#   本机是 Python 3.12，服务器是 3.10，numpy 的可用版本区间不一样
#   （numpy 2.5 已经不支持 3.10 了）。钉死 ==2.5.4 会让服务器装不上，
#   钉死 ==2.2.6 又会让本机的 3.12 退版本。
#   `~=0.162.0` 的意思是「>=0.162.0, <0.163.0」，两边都能装，又不会跳到下一个大版本。
#
# 之前写的是 `>=0.110` 这种「随便升」的写法：哪天上游发个 breaking change，
# 线上 `systemctl restart` 之后就再也起不来，而且你看不出原因。

fastapi~=0.162.0
uvicorn~=0.54.0
requests~=2.34.2

# 只有「向量检索」用到；没装也能跑（会自动退回关键词模式）。
numpy>=2.2,<3.0
