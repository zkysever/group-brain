# 抽象日报（A5）：每天 12:00 一批「怀疑人生」的链接

用户 2026-11-18 的原话：

> 我需要你再做一个视频推荐，每天单独在12点发，一次发10到20个视频，只要链接，
> 我需要你觉得猎奇抽象的视频，让人怀疑人生的那种

所以这是一个**和 A1 选片完全分开**的通道：

| | A1 选片（`app/curator.py`） | A5 抽象日报（`app/weird.py`） |
|---|---|---|
| 时间 | 8–23 点每小时最多 1 条 | 每天 12:00 一批 |
| 数量 | 1 条 | 10–20 条 |
| 内容 | 标题 + UP + 一句判断 + 评论区摘录 | **只有链接** |
| 来源 | B 站「热门」列表 | 用 12 个关键词搜出来的候选 |
| 门槛 | 模型打 4/5 以上 | 模型按「抽象」口味排序 |

## 风格是怎么定下来的

用户给了三条例子，我先把短链解析成 BV，再抓元数据：

| 例子 | BV | 时长 | 播放 |
|---|---|---|---|
| 真是一场酣畅淋漓的司凤啊 | `BV1YZxF69Ep3` | 66s | 242 万 |
| 《 光 速 入 土 》 | `BV1Trs363EN2` | 17s | 197 万 |
| 神之八秒（直视我！） | `BV1bbWd6PE2f` | 16s | 5 万 |

共同点写进了 prompt：**十几秒到一分钟、标题本身就是怪话、看完的反应是「啊？这是什么」**。

## 怎么选

1. **搜**：12 个关键词（抽象 / 整活 / 离谱 / 猎奇 / 魔性 / 鬼畜 / 沙雕 / 逆天 / 怀疑人生 /
   精神污染 / 音MAD / 人类迷惑行为）× 两种排序（按播放 / 按弹幕）× 前 2 页，
   实测能拿到 200+ 条候选。
2. **筛**（规则先砍，省模型钱）：
   - 时长 8–300 秒（太长就不「短」了）
   - 播放 2 万 – 1000 万（太冷门没意思，太爆的多是热搜搬运）
   - 标题含「合集 / 搬运 / 教程 / 解说 / 预告…」直接丢
   - **红线词表**（涉政 / 擦边 / 血腥自伤）在**送模型之前**就过滤掉
3. **挑**：按弹幕率排前 80 条，一次性交给模型排序，返回 10–20 条与一句「哪里怪」。
   逐条打分太贵太慢，一次排序就够。
4. **再拦一道**：模型挑完再用同一个红线词表过一遍——prompt 说不听的时候它真会挑。
5. **发**：写成投递单（`text` 就是若干行 URL），`qq_curator` 插件取走发 QQ 私聊。
   发过的 bvid 写进 `weird_items`，以后不再重复。

模型挂了就按弹幕率兜底（标记 `how: "fallback"`），宁可这天口味一般，也不要空手。

## 为什么红线要放在两个地方

2026-11-18 第一次试跑，模型挑了两条「蒋介石童养媳」的伪史整活——技术上确实抽象，
但这号是学生作品，贴这种东西会出事。所以：

- 池子阶段过滤：模型看不到，也就挑不出来；
- 发送阶段再过滤：万一它绕过 prompt 硬挑，最后一关也能拦住。

## 怎么用

```bash
python scripts/weird_run.py --dry     # 只挑不发，看今天会挑什么
python scripts/weird_run.py           # 正常跑（今天推过就跳过）
python scripts/weird_run.py --force   # 今天已经推过，再来一批
```

网页上也能点：管理面板 → 维护动作 → 「抽象日报」。

cron：

## 已知短板

- **只按标题和分区判断**，没看画面。标题怪的片子内容也可能是标题党；反过来内容很抽象但标题正常的容易漏。
- 候选完全来自搜索结果，**没有个性化**——不看用户看过什么、喜欢什么。
- 「抽象」这类口味很吃个人偏好，前几天的批次最需要他反馈；觉得不准就改 `KEYWORDS` 和 `_SYSTEM` 里那段描述。
- 同一批里的视频可能来自同一个 UP（搜索排名会聚集），没有做 UP 维度去重。
